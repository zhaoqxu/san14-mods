# 一千个曹操

在游戏主菜单的「模组管理」启用后，新局和读入的旧档都会让战局中的武将使用曹操的情义、野心、汉室倾向、好战、外交、物资偏好和建设倾向。玩家和电脑势力均生效。

局内的启用／禁用按钮为灰色。回主菜单后可停用此模组，再读同一个存档即可使用各武将自己的内心值。启用时的手动存档和自动存档均保存武将自身的数值，已经发生的战局进展会保留。

0.1.1 适配简体中文威力加强传承版 Build 25953386，需要支持通用武将内心值接口的 SAN14 Mod Manager，以及已修复空自建武将槽识别的 GameAdapter。

此版本声明主菜单安全热更新／卸载接口。旧版 0.1.0 未声明该接口，首次升级仍可能安排为重启更新；安装本版后，后续兼容版本可由支持该协议的管理器在主菜单尝试热更新。战局内仍不可启停。
