# 存档数据统计

武将表显示成长、实际内政贡献和战斗累计。“武将事迹”记录全势力（含电脑）的单挑胜负平、灭队、攻城、俘虏、擢用、外交、官职、所属势力、名品与身份变化，在人物详情的“名品”右侧点“事迹”按钮，使用原版年表行按日期查看。只记开启后的经历，关闭保留历史，独立“事迹”设置页提供17类记录开关，姓名与城池可跳转原生详情，随存档保存和回退；部分剧情直接改值等特殊路径尚未覆盖。常规开关也可显示本局死亡武将；旧档无基准时从首次开启起记录。

版本 `0.2.0`，内部 ID `save-stats-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod save-stats-mod -Tests -ArtifactRoot build/save-stats-mod
```

作者：[清都jsl](https://space.bilibili.com/3690994744691528)。

## 战功和区域战况

武将表可查看个人战功，武将事迹显示战法明细和灭队地点。自势力和全势力的城市、区域表增加“战斗”页，显示“累计阵亡士兵”。城市按固定所属区域汇总，排除伤兵与转移。开启后开始累计，数据随存档保存和回退。新增原生观察首批支持简体中文传承版。
