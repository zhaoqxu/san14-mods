# 城市／区域表格扩展与阵亡统计

Host ABI v1 可选尾部 `territory_tabs` 提供城市（kind=1）与区域（kind=2）
的原生情报列表页签，适用于自势力和全势力；不修改候选行、势力筛选、对象归属或选择结果。
使用前检查Host大小、指针、服务大小与函数指针。每个owner、kind、key独立注册，
总计最多8个页签，每页最多8列；标题、列名和描述符由Host复制，保留到原生窗口销毁。

注册／注销为UI线程，分别需要`ui.panel`及`game.read.cities`或`game.read.areas`。
refresh可在Host序列化数据上下文执行，允许只读快照与托管存档查询；value只读插件缓存，
输出`int64_t`。缺失返回NOT_FOUND，不能当作0。原生排序使用64位数值；停用／卸载清理注册，
旧窗口不再调用插件。读取对象由Host用当前World表槽与原生类型校验，没有游戏指针暴露给Mod。

`San14BattlefieldApi::query_deaths`追加在原48字节前缀之后。
`SAN14_BATTLEFIELD_API_V1_SIZE`保留旧前缀契约。输入kind、object_id与带struct_size的
`San14BattlefieldDeaths`；城市额外要求`game.read.cities`，其余权限和数据线程规则与battlefield一致。
先查询`capabilities`的`SAN14_BATTLEFIELD_DEATHS`，并通过录制租约选择该类别。
旧Host缺少此尾部时，旧个人贡献服务仍可使用。新表格／阵亡观察首版仅验证简体传承版。

阵亡按同次实际兵力减员减去伤兵净增计算；伤兵结算减少旧伤兵时，其死亡也计入。
观察点在伤兵结算完成之后、被俘／转移伤兵之前，避免把转移当死亡；嵌套结算扣除子调用的
伤兵变化，重复检查点只入账一次。受击地点决定区域，城市累计其固定所属区域的阵亡，
包含各势力在该地域的累计，不随占领变化清零。

新增`SBD1`记录与旧`SBF1`战斗减员分开存储。**旧减员包含伤兵，无法据此补算历史阵亡。**
显示值是从此功能开启后的累计；不存在新记录时从0开始，设置说明明确旧战斗不能补算。
计数u64饱和，原生表格超过INT64_MAX时显示该上限；SDK仍返回完整u64。
新区域记录12字节，固定区域→城市映射仍为全局缓存，不进入每局存档。
读档回退、旧代际拒绝、损坏记录保护均沿用托管session，不逐次写磁盘。

统计插件在上述四种列表提供“战斗”页签、“累计阵亡士兵”列；个人事迹移除地区排行，
保留灭队地点与个人战法明细。真实画面、伤兵与捕获场景、存档往返仍需实机验收。
